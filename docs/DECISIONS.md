# Engineering Decisions

Record significant engineering decisions that affect the project. Do not record every routine coding choice. Link to each relevant entry from the backlog reflection instead of repeating its full explanation. No new entry is required for a backlog that introduces no lasting decision. Preserve previous entries; document a changed decision in a new superseding entry.
